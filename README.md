# Saroka PDF Tools

## Cara menjalankan
1. Install Node.js 18.17+ (disarankan 20) dari https://nodejs.org
2. Buka terminal di folder ini, lalu:
   npm install
3. Salin `.env.local.example` menjadi `.env.local`, isi GROQ_API_KEY
   (gratis di https://console.groq.com/keys)
4. npm run dev
5. Buka http://localhost:3000
